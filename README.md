# Quantum Gate Arcade

A single-page game for exploring X, Z, Y and Hadamard gates without equations. It includes Gate Quest, Gate Lab and Mystery Gate, with generated challenge codes and breakout-room prompts.
This game is created as a teaching aid.



## Using it in class

- **Gate Quest:** students generate a code for individual work or enter the same six-character code to play the same five missions.
- **Gate Lab:** test gates freely from any of six landmark states.
- **Mystery Gate:** choose up to two input states to identify a hidden gate.
- Turn on **Breakout-room prompts** for a gate chooser, predictor and explainer to rotate roles.

The site does not collect students' names or results. A challenge code recreates the mission sequence without storing answers or scores.
